# 교내 분실물 관리 서비스 요구사항 추적표

| 항목 | 내용 |
|---|---|
| 문서 버전 | v0.1 |
| 고객 요구사항 | `docs/고객 요구사항.md` |
| 요구사항 명세서 | `docs/SRS_v0.1.md` |
| 추적 ID 규칙 | `RTM_01`부터 순차 부여 |
| 작성 목적 | 고객 요구사항이 기능·비기능 요구사항과 정책에 반영되었는지 추적하고 누락 및 미정 사항을 식별한다. |

## 1. 추적 기준

| 구분 | 적용 기준 |
|---|---|
| 기본 추적 단위 | 고객 요구사항 `NEEDS_1`~`NEEDS_7`을 우선 추적한다. 고객 요구사항 요약에 직접 나타나지 않지만 범위 또는 공통 제약에서 파생된 항목은 `SC` 또는 `C_1`을 별도 추적한다. |
| 기능 요구사항 | 고객이 기대하는 시스템 동작과 직접 연결된 `FR`을 추적한다. |
| 비기능 요구사항 | 고객 근거가 명확한 업무 효율, 정보 공개 제한, 데이터 및 연동 제약만 추적한다. |
| 일반 품질 속성 | 일반적인 사용성인 `NFR_01`과 일반적인 데이터 정확성인 `NFR_04`는 독립 추적 대상에서 제외한다. 관련 기능의 검증 기준으로 확인한다. |
| 목표치 보완 | 고객이 등록 부담 감소를 요구했으나 목표치가 없으므로 `NFR_02`에 대해 현행 기준 대비 평균 등록 소요 시간 20% 이상 단축을 제안 목표로 둔다. 기준값 측정 후 운영 책임자의 승인이 필요하다. |
| 상태 판정 | `충족`은 SRS에 구현 또는 정책 요구가 정의된 경우, `부분 충족`은 목표나 상세 조건의 결정이 남은 경우, `미정`은 개발 범위 결정이 남은 경우를 의미한다. |
